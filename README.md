# SoundBox

Aplicativo mobile desenvolvido em Flutter para pesquisar músicas utilizando a API do iTunes.

## Funcionalidades

- Listagem de músicas.
- Pesquisa de músicas pelo nome.
- Visualização dos detalhes das músicas.
- Adição e remoção de favoritos durante a sessão.
- Feedback de carregamento.
- Tratamento de erros de conexão.
- Tratamento de pesquisas sem resultados.

## Tecnologias e dependências

- Flutter SDK 3.50.1
- Dart 3.14.0
- Biblioteca http
- API do iTunes

## Como executar

1. Instalar o Flutter SDK.
2. Abrir o projeto no Android Studio.
3. Executar `flutter pub get`.
4. Iniciar um emulador Android.
5. Executar `flutter run`.
